# 🏦 Sistema Bancário em Java (Console)

Projeto desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos (POO), estruturas de controle, listas e validações, simulando um sistema bancário simples via console.

# 📌 Funcionalidades

- Criar contas bancárias
- Depositar valores em uma conta
- Sacar valores de uma conta
- Consultar saldo
- Buscar contas pelo número
- Menu interativo com do-while

# 🛠️ Tecnologias Utilizadas

- Java
- Scanner (entrada de dados)
- ArrayList
- Programação Orientada a Objetos (POO)

# 🧠 Conceitos Aplicados

- Encapsulamento
- Classes e objetos
- Métodos
- Validações de regras de negócio
- Estruturas de repetição (do-while)
- Estrutura de decisão (switch-case)
- Coleções (ArrayList)
- Organização básica de código (Clean Code iniciante)
